# AGShot

A Windows screenshot utility.

## Build

Open `AGShot.sln` in Visual Studio 2022 and build the x64 configuration.

## Use

Launch AGShot and press the configured screenshot hotkey (F1 by default). Select a region, then use the Copy button or Ctrl+C. Press Esc to cancel.
